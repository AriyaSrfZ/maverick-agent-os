# Maverick Agent OS

An autonomous multi-harness agent orchestration environment and operational workflow system integrating browser automation, multi-agent session synchronization, media pipelines, and professional outreach engines.

## Features

- **Browser Automation via CDP**: Automated engagement, connection outreach, and feed scanning via Chrome DevTools Protocol.
- **Carousel & Media Generator**: Node.js and Python document generation pipeline producing styled multi-slide PDF carousels.
- **Cross-Agent Session State**: Shared memory registers, handoff protocols, and agent operational state persistence.
- **Multi-Role Tooling**: Modular automation scripts for routine scheduled tasks, telemetry inspection, and content delivery.

## Layout

```text
├── components/          Reusable UI and visual resume components
├── configs/             Agent configuration and harness parameters
├── docs/                Architecture specs and handoff notes
├── lib/                 Core utility libraries
├── reports/             Automated execution summaries and logs
├── scripts/             Batch execution scripts
├── tools/               CDP automation and browser tooling
└── youtube-ops/         Video automation and council operations
```
