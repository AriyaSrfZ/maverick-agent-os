As autonomous operational history grows, flat linear memory files (`memory.md`) can grow too large, causing context window dilution and retrieval lag.

   * Immutable laws: Operator identity (`Ariya (HaroSS)`), spartan voice, banned words, zero em dashes, safety boundaries (never kill VPN/proxy daemons).

   * `workspaces/youtube-ops/memory.md`: Video render inventory, subtitle styles, channel analytics.
   * `workspaces/bounty-hunting/memory.md`: Active crypto bounties, zero-KYC settlement rails, submission records.
   * `workspaces/maverick-intelligence/memory.md`: Research dossiers, architectural templates, client proposals.
   * `workspaces/agent-harnesses/memory.md`: MCP schemas, OmniRoute configs, cross-device bridge logs.
3. **Tier 3: Active Operational State (`CURRENT.md`)**
   * Single source of truth for current tasks, pending cron jobs, and immediate open loops. Max 150 lines.
4. **Tier 4: Cold Archival Storage (`docs/imported-memories/`)**
   * Completed historical logs, Gemini archives, and past memory dumps preserved for reference without cluttering active agent context.
