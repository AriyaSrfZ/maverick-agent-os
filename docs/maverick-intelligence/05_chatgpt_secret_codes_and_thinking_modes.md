# 100 ChatGPT Secret Codes & Cognitive Modifiers
## Quick-Reference Macro Commands for Agent Harnesses and Prompt Engineering

> "Each code changes how an AI responds by forcing a specific reasoning pattern, lens, or output format. A code gets you started; your context makes the answer useful." — Maverick Maltin

---

## 1. How Cognitive Modifiers Work in Agent Harnesses

Rather than writing multi-paragraph prompt constraints, these shorthand codes activate targeted latent attention pathways in LLMs (Claude, GPT-4o, Gemini 3.8 Flash, Llama 3).

### Single Command Execution:
```text
Use HIDDENASSUMPTIONS to surface the structural blind spots in this architecture proposal, then use NEXTSTEP to output the single highest-priority mitigation action: [Paste Architecture Plan]
```

### Stacking Codes:
```text
Combine REDTEAM + PARETO + TABLE: Aggressively critique this payment reconciliation flow, identify the 20% of vulnerability surface causing 80% of failure modes, and format as a comparative table.
```

## 2. Complete 100-Code Catalog

### A. Core Writing & Voice De-Slopping
| Code | Function & Effect |
|---|---|
| `/human` | Rewrites text to sound natural, varied, and grounded; removes mechanical AI sentence rhythms |
| `/rewrite` | Rephrases text completely while strictly preserving core facts and technical meaning |
| `/improve` | Upgrades clarity, flow, sentence variety, and punchiness |
| `/shorten` | Condenses content into the tightest possible version with zero loss of substance |
| `/expand` | Adds concrete examples, operational depth, and supporting technical context |
| `/simplify` | Converts jargon into plain, everyday language without dumbing down the logic |
| `/formal` | Elevates tone to executive, board-level professional standards |
| `/casual` | Shifts tone to peer-to-peer, conversational engineering dialogue |
